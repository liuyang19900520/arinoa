# App Store 提交材料

每个版本一个目录（格式参照 shadow-player 的 `submissions/`）：
- `README.md`：版本信息、ASC 填写清单、待办
- `<locale>/name.txt subtitle.txt promotional-text.txt description.txt keywords.txt whats-new.txt`：商店文案（zh-Hans / ja / en-US）
- `review-notes.txt`：给审核员的备注（英文）
- `privacy/`：隐私政策三语草稿（需托管成网页）
- `ci-draft/`：截图 CI 草稿（未启用）
